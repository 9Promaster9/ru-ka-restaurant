# Ru-Ka — Сайт ресторана грузинской кухни

Одностраничный сайт для ресторана аутентичной грузинской кухни **Ru-Ka** с интерактивным меню, избранным, списком предварительного выбора блюд, галереей и формой бронирования стола.

Все данные, отсутствующие в исходном описании (цены, вес, контакты, часы работы и отсутствующие фотографии блюд), обозначены как **«НД»**.

## Как добавить фотографии ресторана

1. Распакуйте архив `ru-ka-images.zip` — внутри находится папка `images/` с тремя реальными фотографиями (`1.webp`, `2.webp`, `3.webp`).
2. Загрузите папку `images/` в корень этого репозитория (в GitHub: **Add file -> Upload files**, перетащите папку `images/` и нажмите **Commit changes**).

## Публикация через GitHub Pages

1. Откройте **Settings -> Pages** в этом репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **`main`** и папку **`/ (root)`**, затем нажмите **Save**.
