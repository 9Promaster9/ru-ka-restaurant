# Ru-Ka — Демо-версия сайта ресторана грузинской кухни

Модульная демонстрационная версия сайта ресторана грузинской кухни **Ru-Ka** (г. Саратов, ул. Большая Затонская, 97).

## Структура проекта

- `index.html` — основная страница (архетип «Тёплый крафт и Bento-сетка», без градиентов).
- `css/styles.css` — дизайн-система, переменные `:root`, адаптивная вёрстка от `360px`.
- `data/data.json` — структурированные данные ресторана (описание, контакты, отзывы, статус меню).
- `js/data.js` — резервная копия данных для локального открытия без веб-сервера.
- `js/app.js` — рендеринг данных, блок «Н/Д — Меню сейчас недоступно», вкладки отзывов (Яндекс Карты, 2ГИС, Google Карты), валидация формы бронирования и демо-модальное окно.
- `ru-ka-images/images/` — реальные фотографии зала и блюд ресторана (`1.webp`, `2.webp`, `3.webp`).

## Особенности демо-версии

- В верхней и нижней части сайта размещена пометка о демонстрационной версии.
- Вместо раздела меню отображается крупная заглушка **«Н/Д — Меню сейчас недоступно»**.
- Неизвестные данные (часы работы, средний чек, e-mail, отсутствующие отзывы) обозначены как `Н/Д` без выдуманных значений.
- Форма бронирования работает в демо-режиме с модальным окном предпросмотра.
